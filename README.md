# マナゴルフクラブ GPSナビ（GitHub Pages / PWA版）

## 含まれる機能
- OUT/IN 18ホールのグリーン手前・中央・奥の登録済み座標
- GPS現在地取得、GPS追跡、ヤード距離表示
- ショット地点記録、打つ前の0/1/2打罰記録
- グリーン／カラー到達の記録
- ホールごとのショット数・パット数保存
- ラウンド記録JSONエクスポート、スコア全クリア
- ラウンド後のみ国土地理院の航空写真を読み込み、保存地点とグリーン座標を表示
- PWAマニフェスト、ホーム画面アイコン、Service Worker

## GitHub Pagesへの登録手順（初回）
1. GitHubにログインし、New repositoryで新しいリポジトリを作成します（例: `mana-golf-gps`）。
2. 公開範囲は **Public** を選びます（GitHub Pagesを無料利用する一般的な設定です）。
3. このZIPを解凍し、`index.html`、`manifest.webmanifest`、`sw.js`、`icons` フォルダを含む中身をリポジトリの一番上（root）にアップロードします。ZIPファイル自体を置くだけでは動きません。
4. リポジトリの **Settings → Pages** を開きます。
5. **Build and deployment** の **Deploy from a branch** を選び、Branchを `main`、Folderを `/(root)` にして Saveします。
6. 公開URLが表示されるまで待ちます。URLは通常 `https://ユーザー名.github.io/リポジトリ名/` です。
7. iPhoneのSafariでそのURLを開き、位置情報の使用を許可します。
8. Safariの共有ボタン → **ホーム画面に追加** → 追加します。以後はホーム画面のアイコンから起動できます。

## 更新手順
修正版を受け取ったら、リポジトリのrootにある同名ファイルを置き換えてCommit changesします。ホーム画面アイコンは通常そのまま使えます。

## 大切な注意
- GitHub PagesはHTTPS配信なので、iPhone Safariの位置情報機能を利用できます。位置情報はSafari/iOSの許可設定が必要です。
- GPS追跡は、ゴルフ中にアプリを前面表示した状態で利用してください。iOSはバックグラウンド時の連続GPS取得を保証しません。
- ショット地点・スコア等はiPhoneのブラウザ内 `localStorage` に保存されます。同じ公開URL・同じブラウザ環境で利用してください。Safariの履歴/サイトデータ消去、別ブラウザ利用、端末変更では消える場合があります。定期的にラウンド記録JSONをエクスポートしてください。
- 航空写真とLeaflet地図ライブラリはラウンド後の軌跡確認時にインターネットから読み込みます。航空写真の利用時は通信が発生します。
- 航空写真出典：国土地理院。地図タイル利用条件に従ってください。
- 距離は登録地点までの直線距離です。GPS誤差やコース高低差等で実距離とは異なります。
- 登録座標はユーザー提供値を引き継いでいます。現地測量済みの保証はありません。


## 試験データの完全初期化
「試験データを完全初期化（ショットGPS含む）」を押し、確認画面で「初期化」と入力すると、スコア・ショットGPS地点・ペナルティ・グリーン到達記録を削除します。コース座標やアプリ本体は削除しません。必要な記録は事前にJSONでバックアップしてください。
